# Italian glossary

The plugin's terms in English and in Italian, for skills that talk to an Italian user or write documents whose
`Deliverable language` is Italian. Read it both ways:

- **Input**: an Italian word in a request ("verbale", "SAL", "sollecito") means the plugin concept in the English
  column.
- **Output**: an Italian document uses the first Italian term of the row, the same one every time. Where the row
  says *kept in English*, Italian teams use the English word: write it as it is, without translating it. The
  headings of a document are translated, as its format says, with the [Document headings](#document-headings)
  table; frontmatter keys, register headings and column names stay in English.

The project's own vocabulary, in the `terms` sections of `TAILORING.md`, comes first: a project that calls its
status report "SAL" keeps that word. Scrum terms follow common Italian practice, which keeps the Scrum Guide's
English names.

Sources: the Italian editions of the PMBOK Guide and of ISO 21500 (UNI ISO 21500) where they name the concept,
otherwise common Italian practice. One row per concept; a second Italian term is a synonym to recognize in
requests.
